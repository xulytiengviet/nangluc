# Vietflexmap · Hồ sơ năng lực GIS

Website hồ sơ năng lực công khai của **Vietflexmap**, thành viên **Hệ thống Thông tin Địa lý GIS.VN**.

## Mục tiêu

- Trình bày năng lực GIS, WebGIS, GeoAI, 3D GIS, dữ liệu không gian và tự động hóa.
- Giao diện sáng, tối giản, responsive, không phụ thuộc framework.
- Có thể triển khai trực tiếp bằng GitHub Pages.
- Không công bố số điện thoại, thông tin cá nhân hoặc địa chỉ.

## Cấu trúc

- `index.html` — nội dung và SEO/JSON-LD.
- `styles.css` — giao diện responsive.
- `script.js` — menu mobile, hiệu ứng hiện nội dung và thanh tiến độ.
- `favicon.svg` — biểu tượng Vietflexmap.

## GitHub Pages

Vào **Settings → Pages → Build and deployment**, chọn **Deploy from a branch**, branch `main`, thư mục `/ (root)`.
